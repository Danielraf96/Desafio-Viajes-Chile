# Desafio-Viajes-Chile

Página web de una agencia de viajes ficticia. La hice con HTML, CSS, JavaScript y Bootstrap como ejercicio del módulo Front End.

Contenido de página:

- Un carrusel de imágenes que cambia solo.
- Una sección "Quiénes somos" con íconos y texto.
- Cuatro tarjetas destacadas.
- Un formulario de contacto que avisa si falta algún campo.
- Un menú que cambia de color al bajar y se adapta al celular.

## Tecnologías

HTML, CSS, JavaScript, Bootstrap, Font Awesome y Google Fonts.

## Cómo verla

1. Descarga el repositorio con el botón verde **Code** y luego **Download ZIP**.
2. Descomprime la carpeta.
3. Abre `index.html` con doble clic.
